# Maskan-مسكن
## Project Overview
A housing platform that connects people looking for rental or shared accommodation with suitable housing options and compatible roommates, while helping property owners and agents reach potential tenants in Egypt.

## Project Objectives
- Simplify the process of finding suitable rental and shared housing options in Egypt.
- Help users discover housing options based on their needs, preferences, budget, and preferred location.
- Facilitate roommate matching by helping users identify people with compatible lifestyles and preferences.
- Provide property owners and real estate agents with a platform to reach potential tenants and showcase available properties.

## Project Scope
### In Scope
- User research, including interviews, surveys, and personas.
- User flows and information architecture.
- Low-fidelity wireframes and high-fidelity UI designs.
- Interactive Figma prototype.
- Design system and style guide, including colors, typography, and components.
- Usability testing and design improvements based on feedback.

### Out of Scope
- Backend and database development.
- Application coding and implementation.
- App Store and Google Play deployment.

### Target Users
- **Primary Users:** Students, young professionals, newcomers, and roommate seekers.
- **Secondary Users:** Landlords and real estate agents.
